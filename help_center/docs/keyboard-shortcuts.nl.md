# Sneltoetsen

## Editor-Sneltoetsen

De volgende sneltoetsen zijn beschikbaar op alle editorpagina's (Baan Editor, Coureur Editor, Race Editor, Seizoen Editor, Team Editor, Evenement Editor):

| Sneltoets | Actie | Beschrijving |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Bewerkingsmodus omschakelen** | Schakelt tussen alleen-lezen modus en bewerkingsmodus. Bij het verlaten worden openstaande wijzigingen gevalideerd en opgeslagen. |
| `Cmd/Ctrl + Z` | **Ongedaan maken** | Maakt de laatste wijziging in bewerkingsmodus ongedaan. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Opnieuw** | Past de meest recent ongedaan gemaakte wijziging in bewerkingsmodus opnieuw toe. |
| `→` / `]` / `E` | **Volgend item** | Navigeert naar het volgende item in alleen-lezen modus. |
| `←` / `[` / `Q` | **Vorig item** | Navigeert naar het vorige item in alleen-lezen modus. |
| `X` | **Alles uitvouwen / samenvouwen** | Vouwt alle secties in de editor uit of samen. |
