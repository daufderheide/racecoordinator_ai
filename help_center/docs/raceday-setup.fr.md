# Configuration du Jour de Course

L'écran de **Configuration du Jour de Course** est le centre de lancement de toutes les épreuves dans Race Coordinator AI. Vous y configurez les pilotes, choisissez formats et saisons, vérifiez les rotations et lancez les courses officielles ou de démonstration.

## Aperçu {: #overview }

L'écran s'organise en deux zones principales :

- **Zone des Pilotes (Gauche)** : Répartie en **Pilotes Disponibles** (l'effectif prêt à courir) et **Pilotes en Course** (les participants sélectionnés et leur ordre de départ).
- **Configuration & Contrôles (Droite)** : Cartes de démarrage rapide pour les courses récentes, sélecteurs de course et de saison, résumés de configuration et boutons de lancement.
- **Barre de Menu Supérieure** : Accès rapide aux gestionnaires, fichiers de course et préférences.

## Pilotes Disponibles {: #available-drivers }

La section **Pilotes Disponibles** liste tous les pilotes et équipes éligibles de votre base de données :

- **Ajouter des Pilotes** : Glissez-déposez un pilote vers la liste de course ou double-cliquez pour l'ajouter en fin de liste.
- **Recherche & Filtres** : Filtrez en temps réel par nom ou surnom. Naviguez au clavier et appuyez sur Entrée pour ajouter.
- **Filtres d'Étiquettes** : Filtrez les pilotes par étiquettes colorées.
- **Gestion des Pilotes et Équipes** : Cliquez sur **Équipes** ou **Pilotes** pour ouvrir les gestionnaires dédiés.
- **Validation de l'Effectif** : Les pilotes sélectionnés ne peuvent être ajoutés en double. Si une équipe court, ses membres individuels sont masqués de la liste disponible.

## Pilotes en Course {: #racing-drivers }

La section **Pilotes en Course** rassemble les compétiteurs sélectionnés :

- **Ordre de Départ (Seeding)** : L'ordre dans cette liste détermine les positions de départ des rotations. Glissez les pilotes pour ajuster l'ordre.
- **Retirer des Pilotes** : Double-cliquez sur un pilote ou glissez-le hors de la liste pour le retirer.
- **Barre d'Actions** :
    - **Voir l'Effectif Complet** : Affiche la liste complète de la base de données.
    - **Ajouter Tout (+)** : Ajoute tous les pilotes disponibles en un clic.
    - **Retirer Tout (-)** : Vide la liste de course.
    - **Aléatoire (Shuffle)** : Mélange aléatoirement les positions de départ.
- **Recherche en Course** : Filtrez les participants ou appuyez sur Entrée pour les retirer.

## Sélection de Course et de Saison {: #race-and-season-selection }

Permet de choisir l'épreuve à disputer :

- **Sélecteur de Course** : Choisissez parmi les courses simples ou événements multi-courses. Chaque format définit rotations, classement et fin d'épreuve.
- **Recherche de Course** : Filtrez rapidement courses et événements par nom.
- **Sélecteur de Saison** : Associez la course à un championnat ou choisissez **Aucune** pour une course isolée.
- **Résumé de Configuration & Classement** : Présente les détails (règles, carburant, mode mains libres, piste, thème) ou le classement du championnat.
- **Modifier la Course** : Cliquez sur l'icône de crayon pour ajuster les paramètres dans l'Éditeur de Course.

## Démarrage Rapide {: #quick-start-races }

Deux grandes cartes de **Démarrage Rapide** présentent les deux courses les plus récentes. Un clic sélectionne immédiatement la configuration.

## Démarrer une Course {: #starting-a-race }

Quand la liste des partants et le format sont prêts, utilisez les boutons d'action :

- **Démarrer Course** : Lance l'épreuve officielle avec le matériel de détection de piste actif.
- **Course Démo** : Simule une course sans capteurs pour tester les affichages et annonces.
- **Rejoindre / Terminer** : Permet de réintégrer une course active ou de la clore proprement.

## Barre de Menu {: #menu-bar }

La barre supérieure regroupe toutes les fonctionnalités :

- **Fichier** : Charger des courses, voir l'historique, exporter/importer des paramètres ou quitter.
- **Configuration** : Gestionnaires pour pilotes, équipes, pistes, courses, saisons, thèmes et dispositions.
- **Options** : Interface utilisateur, paramètres serveur, langue, mises à jour et mode démo.
- **Aide** : Niveaux de journaux, boîte de dialogue À propos et Centre d'aide.
