# Atalhos de Teclado

## Atalhos do Editor

Os seguintes atalhos estão disponíveis em todas as páginas do editor (Editor de Pistas, Editor de Pilotos, Editor de Corridas, Editor de Temporadas, Editor de Equipes, Editor de Eventos):

| Atalho | Ação | Descrição |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Alternar Modo de Edição / Leitura** | Alterna entre o modo somente leitura e o modo de edição. Ao sair, as alterações pendentes são validadas e salvas. |
| `Cmd/Ctrl + Z` | **Desfazer** | Reverte a última alteração no modo de edição. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Refazer** | Reaplica a alteração revertida mais recentemente no modo de edição. |
| `→` / `]` / `E` | **Próximo Item** | Navega para o próximo item no modo somente leitura. |
| `←` / `[` / `Q` | **Item Anterior** | Navega para o item anterior no modo somente leitura. |
| `X` | **Expandir / Recolher Tudo** | Expande ou recolhe todas as seções no editor. |
