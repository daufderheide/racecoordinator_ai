# Tastenkürzel

## Editor-Tastenkombinationen

Die folgenden Tastenkombinationen stehen auf allen Editor-Seiten zur Verfügung (Strecken-Editor, Fahrer-Editor, Renn-Editor, Saison-Editor, Team-Editor, Event-Editor):

| Tastenkürzel | Aktion | Beschreibung |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Bearbeitungsmodus umschalten** | Schaltet zwischen schreibgeschütztem Modus und Bearbeitungsmodus um. Beim Verlassen werden ausstehende Änderungen validiert und gespeichert. |
| `Cmd/Ctrl + Z` | **Rückgängig** | Macht die letzte Änderung im Bearbeitungsmodus rückgängig. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Wiederholen** | Wendet die zuletzt rückgängig gemachte Änderung im Bearbeitungsmodus wieder an. |
| `→` / `]` / `E` | **Nächstes Element** | Wechselt im schreibgeschützten Modus zum nächsten Element. |
| `←` / `[` / `Q` | **Vorheriges Element** | Wechselt im schreibgeschützten Modus zum vorherigen Element. |
| `X` | **Alle erweitern / reduzieren** | Erweitert oder reduziert alle Abschnitte im Editor. |
