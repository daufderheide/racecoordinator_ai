# Raccourcis Clavier

## Raccourcis de l'Éditeur

Les raccourcis suivants sont disponibles sur toutes les pages d'édition (Éditeur de Circuits, Éditeur de Pilotes, Éditeur de Courses, Éditeur de Saisons, Éditeur d'Équipes, Éditeur d'Événements) :

| Raccourci | Action | Description |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Basculer entre Mode Édition / Lecture** | Bascule entre le mode lecture seule et le mode édition. En quittant, les modifications sont validées et enregistrées. |
| `Cmd/Ctrl + Z` | **Annuler** | Annule la dernière modification en mode édition. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Rétablir** | Réapplique la modification la plus récemment annulée en mode édition. |
| `→` / `]` / `E` | **Élément Suivant** | Navigue vers l'élément suivant en mode lecture seule. |
| `←` / `[` / `Q` | **Élément Précédent** | Navigue vers l'élément précédent en mode lecture seule. |
| `X` | **Tout développer / réduire** | Développe ou réduit toutes les sections de l'éditeur. |
