## Editor Shortcuts

The following shortcuts are available across all editor pages (Track Editor, Driver Editor, Race Editor, Season Editor, Team Editor, Event Editor):

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Toggle Edit / View Mode** | Switches between Read-Only Mode and Edit Mode. When exiting Edit Mode, pending changes are validated and saved. |
| `Cmd/Ctrl + Z` | **Undo** | Reverts the last change in Edit Mode. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Redo** | Reapplies the most recently reverted change in Edit Mode. |
| `→` / `]` / `E` | **Next Item** | Navigates to the next entity in Read-Only Mode. |
| `←` / `[` / `Q` | **Previous Item** | Navigates to the previous entity in Read-Only Mode. |
| `X` | **Expand / Collapse All** | Expands or collapses all sections in the editor. |
