# Scorciatoie da Tastiera

## Scorciatoie dell'Editor

Le seguenti scorciatoie sono disponibili in tutte le pagine dell'editor (Editor Tracciati, Editor Piloti, Editor Gare, Editor Stagioni, Editor Team, Editor Eventi):

| Scorciatoia | Azione | Descrizione |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Attiva/Disattiva Modalità Modifica** | Alterna tra modalità sola lettura e modalità modifica. Uscendo, le modifiche in sospeso vengono convalidate e salvate. |
| `Cmd/Ctrl + Z` | **Annulla** | Annulla l'ultima modifica in modalità modifica. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Ripristina** | Riapplica la modifica annullata più di recente in modalità modifica. |
| `→` / `]` / `E` | **Elemento Successivo** | Passa all'elemento successivo in modalità sola lettura. |
| `←` / `[` / `Q` | **Elemento Precedente** | Passa all'elemento precedente in modalità sola lettura. |
| `X` | **Espandi / Comprimi Tutto** | Espande o comprime tutte le sezioni nell'editor. |
