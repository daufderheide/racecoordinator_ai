## Crash and Learn (CNL) {: #crash-and-learn }

**Crash and Learn (CNL)** ist ein Rennformat-Modifikator, der Deslots (Crashes) bestraft und diszipliniertes Fahren fördert. Er kann über jedes Standard-Rennformat (wie Round Robin, Step Up, zeit- oder rundenbasiert) gelegt werden.

Bei Aktivierung:
- **Crash-Limits & Disqualifikation**: Fahrern wird eine maximale Anzahl erlaubter Crashes zugewiesen, bevor sie für den Lauf disqualifiziert (DQ) werden. Bei Disqualifikation wird der Bahnstrom abgeschaltet, die schwarze Flagge gezeigt und der Fahrer hinter nicht-disqualifizierten Teilnehmern eingestuft.
- **Automatische Deslot-Erkennung**: Das System kann Crashes anhand einer Rundenzeitschwelle oder über spurbezogene Chaosschalter automatisch erkennen.
- **Konfigurierbare Strafen**: Rundenabzüge, Zeitstrafen oder prozentuale Wertungskürzungen bei Disqualifikation können flexibel eingestellt werden.
- **Heat-Reset-Optionen**: Veranstalter können festlegen, ob Crash-Zähler und Disqualifikationen zu Beginn jedes Laufs zurückgesetzt werden oder über das gesamte Rennen erhalten bleiben.

Vollständige Konfigurationsoptionen finden Sie unter [Renn-Editor: Crash and Learn](race-editor.de.md#crash-and-learn). Details zum Rennbetrieb finden Sie unter [Rennbetrieb: Crash-and-Learn-Betrieb](raceday-operation.de.md#crash-and-learn-operations).
