## Crash and Learn (CnL) {: #crash-and-learn }

**Crash and Learn (CNL)** is an event format modifier that penalizes deslots (crashes) and encourages disciplined driving. It can be layered on top of any standard race format (such as Round Robin, Step Up, Timed, or Lap-based racing).

When enabled:
- **Crash Limits & Disqualification**: Drivers are given a maximum number of allowable crashes before being disqualified (DQ'd) from the heat. Disqualified drivers have lane power cut, show the black flag, and are ranked below non-disqualified competitors.
- **Automated Deslot Detection**: The system can automatically detect crashes based on a lap time threshold or through trackside per-lane call buttons.
- **Configurable Penalties**: Race organizers can apply lap penalties, time penalties, or score scaling upon disqualification.
- **Heat Reset Flexibility**: Organizers can configure whether crash counts and disqualification statuses reset at the start of each heat or persist across the entire race.

For complete configuration options, see [Race Editor: Crash and Learn](race-editor.md#crash-and-learn). For live race operation details, see [Race Day Operation: Crash and Learn Operations](raceday-operation.md#crash-and-learn-operations).
