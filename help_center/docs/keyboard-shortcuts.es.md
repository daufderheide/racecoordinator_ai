# Atajos de Teclado

## Atajos del Editor

Los siguientes atajos están disponibles en todas las páginas de edición (Editor de Pistas, Editor de Pilotos, Editor de Carreras, Editor de Temporadas, Editor de Equipos, Editor de Eventos):

| Atajo | Acción | Descripción |
| :--- | :--- | :--- |
| `Cmd/Ctrl + E` | **Alternar Modo de Edición / Lectura** | Alterna entre el modo de solo lectura y el modo de edición. Al salir, los cambios pendientes se validan y se guardan. |
| `Cmd/Ctrl + Z` | **Deshacer** | Revierte el último cambio en modo de edición. |
| `Cmd/Ctrl + Shift + Z` / `Cmd/Ctrl + Y` | **Rehacer** | Vuelve a aplicar el cambio revertido más recientemente en modo de edición. |
| `→` / `]` / `E` | **Elemento Siguiente** | Navega al siguiente elemento en modo de solo lectura. |
| `←` / `[` / `Q` | **Elemento Anterior** | Navega al elemento anterior en modo de solo lectura. |
| `X` | **Expandir / Contraer Todo** | Expande o contrae todas las secciones en el editor. |
