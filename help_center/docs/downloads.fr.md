# Téléchargements

## Canaux de publication et mises à jour automatiques { #release-channels }

Race Coordinator AI propose plusieurs canaux de mise à jour afin que les directeurs de course puissent choisir le flux de versions qui convient le mieux à leurs besoins. Vous pouvez configurer votre canal à tout moment depuis **Options → Mises à jour automatiques** dans la configuration de la course ou dans la barre de menu de la course.

### 🟢 Versions de production
Versions officielles prêtes pour la production ayant subi des vérifications approfondies et entièrement validées pour toutes les opérations de club, de tournoi et de course générale. Recommandé lorsque la stabilité opérationnelle maximale est votre priorité absolue.

### 🟡 Versions bêta
Versions stables et complètes publiées pendant les cycles de développement actif, subissant des tests communautaires finaux et une vérification en course réelle avant d'être promues en versions de production officielles. L'installation des versions bêta est recommandée pour tester de nouvelles fonctionnalités, donner votre avis et vous assurer que la version finale de production soit aussi solide et stable que possible. Les versions bêta incluent généralement de nouvelles fonctionnalités (configurations de course, interfaces de piste, etc.). Une version bêta sera promue en version de production après une courte période au cours de laquelle les utilisateurs ne signalent aucun problème avec la nouvelle version candidate.

### 🔵 Versions quotidiennes alpha
Versions automatisées générées quotidiennement à partir de la branche de développement actif. Bien que généralement stables pour une utilisation quotidienne, les versions alpha contiennent des fonctionnalités prototypes et des améliorations en cours qui peuvent évoluer rapidement. Recommandé pour les passionnés et contributeurs souhaitant un accès anticipé aux fonctionnalités de pointe.

### ⚪ Désactivé
Désactive les vérifications automatiques des mises à jour en arrière-plan. Vous pouvez toujours vérifier manuellement les mises à jour à tout moment via l'option de menu **Vérifier les mises à jour**.
